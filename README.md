# FF14 固定予定表アプリ (`FF14RaidSchedule`)

FF14の8人固定メンバー（MT / ST / H1 / H2 / D1〜D4）で活動日程を調整するためのWebアプリです。  
ログイン不要でそのまま入力でき、データは `data/schedule.json` に永続保存されます。

## 主な機能

- **FF14 8人ロール対応**: MT / ST / H1 / H2 / D1 / D2 / D3 / D4 のロール色分け表示と、メンバー名・ジョブの編集（全バトルジョブ＋バスティオン・ゼファー選択および手入力対応）
- **火曜リセット基準の週表示**: FF14の週リセット（火曜始まり）に対応（設定から月曜・日曜始まりにも変更可能）。1週間 / 2週間表示切替
- **○・△・× + コメント入力**: 遅刻・早退などのメモ（プリセットチップ付き）を入力可能。クイック入力モードでクリック切替にも対応
- **一括入力**: 自分のロールを選択すると、未入力の日をまとめて「○」「×」にしたり、前の週からコピー可能
- **全員○ハイライト & 活動日確定**: 8人全員参加可能な日を自動ハイライトし、活動確定日（時間・メモ付き）を登録可能
- **Discord用テキスト出力**: 活動確定日・候補日とメンバーのコメントをDiscord貼り付け用Markdownでワンクリックコピー
- **Discord 自動通知 & スラッシュコマンド (`/schedule`)**: 活動確定日の当日指定時刻に自動通知（Webhook / Bot対応）。Bot トークンを設定すると Discord 上から `/schedule` コマンドで特定の週の予定を取り出し可能

## Discord Bot スラッシュコマンド (`/schedule`)

設定画面の「Discord Bot」または環境変数 `DISCORD_BOT_TOKEN` に Bot トークンを設定してサーバーを起動すると、自動で `/schedule` コマンドが登録されます。

- `/schedule` — 今週の予定を表示
- `/schedule week:来週` — 先週 / 今週 / 来週 / 再来週 / 3週間後 を選択して表示
- `/schedule date:12/1`（または `2026-12-01`） — 指定した日付を含む週の予定を表示
- `detail:True` — 各メンバーの ○/△/× 一覧も含めて表示
- `private:True` — 自分だけに見える返信として表示

※ 環境変数 `DISCORD_GUILD_ID` にサーバーIDを指定すると、そのサーバーへ即時反映されます（未指定時はグローバルコマンド登録）。

## セットアップ & 起動

```bash
npm install
```

### 開発モード（API + Viteフロントエンド同時起動）

```bash
npm run dev
```

- フロントエンド: http://localhost:5173
- APIサーバー: http://localhost:3001

### 本番ビルド & 起動（単一サーバーで配信）

```bash
npm run build
npm start
```

- アプリ本体: http://localhost:3001
